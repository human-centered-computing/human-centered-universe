# HCU Story Node Builder

The page now includes a visible **How to use** section at the top.

Usage flow:

1. Select the story's source language.
2. Paste the story and optional metadata.
3. Create and copy the AI prompt.
4. Paste the AI JSON result and validate it.
5. Export the GitHub-ready ZIP.

English remains the canonical output language. Other languages are stored as translation layers under the same story ID.
