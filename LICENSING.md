# Licensing Guide

Human-Centered Universe is a hybrid creative and software project. Different artifact types use licenses designed for their function.

| Artifact | Default license |
| --- | --- |
| Application, website, scripts, APIs, game/software code | GNU AGPL-3.0 |
| Book text, stories, narrative nodes | CC BY-SA 4.0 |
| Translations of project creative content | CC BY-SA 4.0 |
| Original illustrations and creative artwork | CC BY-SA 4.0 |
| Original narration, audio, music, video, animation | CC BY-SA 4.0 |
| Game narrative, dialogue, characters, worldbuilding and expressive assets | CC BY-SA 4.0 |
| Third-party libraries and assets | Their original license |
| Personal photographs / likenesses | Only as specifically authorized |
| Trademarks / project identity marks | Not automatically licensed by AGPL or CC BY-SA |

## Why two licenses?

Creative Commons recommends software-specific licenses for software, while CC licenses are suitable for documentation and separate artistic elements such as game art or music.

Human-Centered Universe therefore uses:

- **AGPL-3.0** to keep the software layer open, including relevant modified network-deployed versions.
- **CC BY-SA 4.0** to keep the book and creative universe shareable, adaptable, attributable, and ShareAlike.

## Contribution rule

The default inbound contribution rule mirrors the outbound license:

- contribute code → AGPL-3.0,
- contribute original creative/book/media content → CC BY-SA 4.0.

Contributors retain copyright in their own work unless a separate written agreement expressly states otherwise.

## Mixed files

If a single file materially combines software and creative content, maintainers should separate the components where practical or add an explicit file-level licensing notice.

## Rights review

Before adding media or content, contributors should verify that they have authority to license it under the applicable project license.

When rights are uncertain, do not assume that a public upload, an AI-generated asset, a social-media image, a historical image, or an online source is automatically reusable.

See:

- `LICENSE` for AGPL-3.0 software terms.
- `CONTENT_LICENSE.md` for CC BY-SA 4.0 creative-content terms.
