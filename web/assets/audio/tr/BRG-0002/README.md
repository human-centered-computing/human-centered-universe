# BRG-0002 audio folder

Bu klasör BRG-0002 Türkçe profesyonel anlatıcı kaydının kalıcı yerel kopyası için ayrılmıştır.

Şu an Narrator Mode v1 aşağıdaki üretilen ses bağlantısını doğrudan kullanır:

https://www.aidocmaker.com/g0/audio?name=c37759eca64d4989b5103480e65147f9

İleride bu kayıt MP3 olarak indirilip aşağıdaki adla bu klasöre konabilir:

BRG-0002-narration.mp3

Ardından `web/assets/narrator.v1.js` içindeki `CONFIG["BRG-0002:tr"].audio`
değeri şu yapılır:

./assets/audio/tr/BRG-0002/BRG-0002-narration.mp3
