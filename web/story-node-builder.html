Human-Centered Universe

Idea → Story Node Builder

Enter an idea, mature it through the HUMAN / LIGHT / DARK centers, generate a complete story in the language you choose, classify the resulting story, and export a GitHub-ready package.

Core rule: LIGHT is not “good”, DARK is not “evil”, and HUMAN is not a neutral midpoint. The same idea must live through all three centers and emerge more mature than it entered.
Language policy: Idea language and story language are independent. The literary story is generated in the selected story language. English remains the canonical repository layer; a non-English story is stored as a translation layer under the same story ID together with a faithful English canonical version.

How to use

  1. Choose the idea language and story language.
  2. Write the idea you want to mature. A single sentence is enough.
  3. Click Create Three-Center Story Prompt.
  4. Send the prompt to an AI system that can return JSON.
  5. Paste the AI JSON into AI JSON Result and click Process and Validate.
  6. Review the generated story, HUMAN / LIGHT / DARK classification and observer choices.
  7. Click Create GitHub ZIP to produce the story-node package.
