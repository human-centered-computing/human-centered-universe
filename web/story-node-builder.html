Human-Centered Universe

Story Node Builder

Create a story node, classify it in the HUMAN / LIGHT / DARK state space, generate observer choices, and export a GitHub-ready package.

Language policy: English is the canonical and default language. Additional languages are optional translation layers of the same story ID. The interface remains English.

How to use

  1. Select the source language of your story. If it is not listed, choose Other / custom language code.
  2. Paste the story into the Story Content field. You may also add a title, culture tags, belief context, and a related existing node.
  3. Click Create AI Prompt, copy the generated prompt, and send it to an AI system that can return JSON.
  4. Paste the AI JSON response into AI JSON Result and click Process and Validate. The builder will calculate HUMAN / LIGHT / DARK scores, place the story in the triangular state space, validate coverage, and generate observer choices.
  5. When the analysis is valid, click Create GitHub ZIP. The package will include the canonical English story, optional translation layers, meta.json, and analysis.json in the correct story-node structure.
Important: English is always the canonical output language. The selected source language is preserved only as a translation layer when it is not English.
