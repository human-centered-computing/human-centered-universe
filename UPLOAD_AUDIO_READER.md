# GitHub yükleme

1. ZIP'i aç.
2. `hcu-audio-reader-v1` klasörünün içine gir.
3. İçindeki `web` ve `docs` klasörlerini `human-centered-universe` repository köküne yükle.
4. `web/index.html` için **Replace / overwrite** işlemini kabul et.
5. Commit mesajı: `Add browser-native audio reader`
6. Actions altında `Validate Universe` ve `Deploy Interactive Reader` işlemlerinin yeşil ✓ olmasını kontrol et.

Not: Paket mevcut Göbekli Tepe görsel katmanını koruyan `web/index.html` sürümünü içerir.
