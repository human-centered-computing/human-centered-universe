# نظام الترجمة

> حالة الترجمة: مسودة بمساعدة الذكاء الاصطناعي، بانتظار مراجعة لغوية بشرية.

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

## المصدر المضبوط والطبقة المرجعية
المصدر التحريري التركي ← ترجمة آلية إلى الإنجليزية ← مراجعة بشرية ← الإنجليزية المرجعية؛ ثم ترجمة آلية إلى de وes وfr وit وru وzh-CN وja وar وku وpt. التركية والإنجليزية تحت رقابة بشرية، واللغات العشر الأخرى منتجة بالذكاء الاصطناعي بلا مراجعة بشرية.

## قاعدة البيانات الوصفية
- `en`: `{"status":"canonical","human_reviewed":true}`
- `tr`: `{"status":"reviewed","human_reviewed":true}`
- سائر اللغات: `{"status":"machine_draft","human_reviewed":false}`
لا ترقّ إلى reviewed قبل مراجعة لغوية بشرية فعلية.

## الطبقات واللغة البديلة
تبقى الترجمة تحت معرف القصة نفسه في `content/<language-code>.md`. عند غياب اللغة يعرض القارئ الإنجليزية المرجعية.

## التكييف الثقافي
ليس ترجمة؛ عقدة قصة جديدة بمعرف وعلاقات صريحة.
