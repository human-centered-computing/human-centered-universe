# Connection Types

Every story is already connected to the universe through its HUMAN / LIGHT / DARK weights. Direct story-to-story links are optional semantic relations.

| Type | Meaning |
|---|---|
| quantum_echo | A narrative echo across distant observations or states; not automatically physical entanglement |
| echo | A similar human question or pattern appearing elsewhere |
| contrast | A story tests another through an opposing value, condition or outcome |
| cause | Direct causal relation inside a narrative path |
| memory | Memory, record, tradition, trauma or inherited trace |
| future | A relation involving a possible future or future-to-past record |
| character | Shared character |
| place | Shared place |
| artifact | Shared object, technology, text or symbol |
| theme | Shared theme |
| transformation | One node changes how another is interpreted |
| parallel | Parallel possibilities without a shared causal origin |

Story links supplement the triangular state space; they do not replace it.
