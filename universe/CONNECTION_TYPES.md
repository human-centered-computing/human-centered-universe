# Connection Types

| Type | Meaning |
|---|---|
| quantum_echo | Repeating sign, number, rhythm, geometry or event pattern across distant stories |
| echo | A similar human question appearing in a different cultural context |
| contrast | A story tests another story through an opposing value or outcome |
| cause | Direct causal relationship |
| memory | Memory, record, tradition, trauma or inherited trace |
| future | Link across possible futures or future-to-past records |
| character | Shared character |
| place | Shared place |
| artifact | Shared object, technology, text or symbol |
