# Upload to GitHub Desktop

1. Extract this ZIP.
2. Open your local `human-centered-universe` repository folder.
3. Copy **all files and folders inside this package** into that repository folder.
4. When asked about files with the same name, choose **Replace** only if you want this package to become the current baseline.
5. Open GitHub Desktop.
6. Review the Changes list.
7. Commit message:

   `Sync complete Human-Centered Universe structure`

8. Click **Commit to main**.
9. Click **Push origin**.

Do not upload the ZIP file itself into the repository. Upload/copy the extracted contents.
