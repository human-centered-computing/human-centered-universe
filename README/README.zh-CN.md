## 三中心模型

**Human-Centered Universe（HCU）** 是一个开放、持续生长且没有预设上限的叙事宇宙，由相互连接的故事节点、Observer 选择，以及与三个中心的百分比关系构成。

- **HUMAN CENTER** — 人的意义、尊严、能动性、关系与责任
- **LIGHT CENTER** — 知识、秩序、可解释性、安全与验证
- **DARK CENTER** — 可能性、自由、不确定性、创造与转化

```text
HUMAN + LIGHT + DARK = 100
```

每个故事都可以保持为独立思想，同时通过与其他故事的连接参与形成更大的意识结构。

> **每个故事都是一种独立思想。连接形成更大的意识。**

## Observer 模型

**在线宇宙：** [https://human-centered-computing.github.io/human-centered-universe/](https://human-centered-computing.github.io/human-centered-universe/)

每次有意义的选择都会改变 HUMAN / LIGHT / DARK。系统重新计算 Observer State 和与三个中心的距离，再从未读故事中推荐最接近当前状态的节点。

> **宇宙会推荐道路，但不会把 Observer 困在其中。**

## Quantum Time

HCU 不仅按照：

```text
昨天 → 今天 → 明天
```

组织时间。时间意义也可以由节点之间的关系以及 Observer 的观察顺序产生。

> **Nodes create space. Relationships create meaning. Choices create movement. Observation creates time.**

Quantum Time 是一种关系型叙事与哲学模型，并不是对新物理定律的主张。
