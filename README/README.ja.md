## 三中心モデル

**Human-Centered Universe（HCU）** は、相互接続されたストーリーノード、Observer の選択、三つの中心との割合関係から構成される、開かれた生きた無境界の物語宇宙です。

- **HUMAN CENTER** — 人間的意味、尊厳、主体性、関係、責任
- **LIGHT CENTER** — 知識、秩序、説明可能性、安全、検証
- **DARK CENTER** — 可能性、自由、不確実性、創造、変容

```text
HUMAN + LIGHT + DARK = 100
```

各ストーリーは独立した思考のままでありながら、他のストーリーとのつながりを通して、より大きな意識構造に参加できます。

> **各ストーリーは独立した思考であり、つながりがより大きな意識をつくる。**

## Observer モデル

**ライブ宇宙：** [https://human-centered-computing.github.io/human-centered-universe/](https://human-centered-computing.github.io/human-centered-universe/)

意味のある選択ごとに HUMAN / LIGHT / DARK が変化します。Observer State と三中心からの距離が再計算され、現在の状態に最も近い未読ストーリーが推薦されます。

> **宇宙は道を推薦するが、Observer をその道に閉じ込めない。**

## Quantum Time

HCU は

```text
昨日 → 今日 → 明日
```

だけに依存しません。時間的な意味は、ノード間の関係と Observer がそれらを観測する順番からも生まれます。

> **Nodes create space. Relationships create meaning. Choices create movement. Observation creates time.**

Quantum Time は関係的な物語・哲学モデルであり、新しい物理法則の主張ではありません。
