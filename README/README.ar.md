## نموذج المراكز الثلاثة

**Human-Centered Universe (HCU)** كون سردي مفتوح، حي، وغير محدود، يتكوّن من عقد قصصية مترابطة واختيارات Observer وعلاقات نسبية مع ثلاثة مراكز:

- **HUMAN CENTER** — المعنى الإنساني والكرامة والاختيار والعلاقة والمسؤولية
- **LIGHT CENTER** — المعرفة والنظام وقابلية التفسير والأمان والتحقق
- **DARK CENTER** — الاحتمال والحرية وعدم اليقين والإبداع والتحول

```text
HUMAN + LIGHT + DARK = 100
```

يمكن لكل قصة أن تبقى فكرة مستقلة، بينما تصنع العلاقات بين القصص وعياً أوسع.

> **كل قصة فكرة مستقلة. الروابط بين القصص تصنع وعياً أكبر.**

## نموذج Observer

**الكون الحي:** [https://human-centered-computing.github.io/human-centered-universe/](https://human-centered-computing.github.io/human-centered-universe/)

كل اختيار ذي معنى يغيّر HUMAN / LIGHT / DARK. ثم يُعاد حساب Observer State والمسافة من المراكز الثلاثة، وتُقترح القصة غير المقروءة الأقرب إلى حالة القارئ.

> **الكون يقترح مساراً، لكنه لا يسجن Observer داخله.**

## Quantum Time

لا يعتمد HCU حصراً على:

```text
الأمس → اليوم → الغد
```

بل يمكن للمعنى الزمني أن ينشأ من علاقات العقد وترتيب ملاحظتها.

> **Nodes create space. Relationships create meaning. Choices create movement. Observation creates time.**

Quantum Time نموذج سردي وفلسفي علائقي، وليس ادعاءً بقانون فيزيائي جديد.
