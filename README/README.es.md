## Modelo de tres centros

**Human-Centered Universe (HCU)** es un universo narrativo abierto, vivo y sin límite predefinido, formado por nodos de historias interconectados, elecciones del Observer y relaciones porcentuales con tres centros.

- **HUMAN CENTER** — significado humano, dignidad, agencia, relación y responsabilidad
- **LIGHT CENTER** — conocimiento, orden, explicabilidad, seguridad y verificación
- **DARK CENTER** — posibilidad, libertad, incertidumbre, creatividad y transformación

```text
HUMAN + LIGHT + DARK = 100
```

Cada historia puede seguir siendo un pensamiento independiente. Sus conexiones con otras historias crean una conciencia narrativa más amplia.

> **Cada historia es un pensamiento distinto. Las conexiones crean una conciencia mayor.**

## Modelo del Observer

**Universo en vivo:** [https://human-centered-computing.github.io/human-centered-universe/](https://human-centered-computing.github.io/human-centered-universe/)

Cada elección significativa modifica HUMAN / LIGHT / DARK. El Observer State se recalcula, se actualiza la distancia a los tres centros y se recomienda la historia no leída más cercana al perfil actual.

> **El universo recomienda un camino; no encierra al Observer en él.**

## Quantum Time

HCU no depende únicamente de:

```text
ayer → hoy → mañana
```

El significado temporal también puede surgir de las relaciones entre nodos y del orden en que el Observer los encuentra.

> **Nodes create space. Relationships create meaning. Choices create movement. Observation creates time.**

Quantum Time es un modelo narrativo y filosófico relacional, no una afirmación sobre una nueva ley física.

## Creador del Universo — Story Node Builder

**Abrir:** [https://human-centered-computing.github.io/human-centered-universe/story-node-builder.html](https://human-centered-computing.github.io/human-centered-universe/story-node-builder.html)

1. Elegir el idioma de origen.
2. Añadir la historia.
3. Crear el prompt de análisis con IA.
4. Obtener JSON estructurado.
5. Devolver el JSON al Builder.
6. Validar los 30 criterios.
7. Calcular HUMAN / LIGHT / DARK.
8. Posicionar la historia en el triángulo.
9. Crear elecciones del Observer.
10. Conectar con nodos existentes.
11. Ejecutar Coverage Audit.
12. Exportar el paquete para GitHub.
