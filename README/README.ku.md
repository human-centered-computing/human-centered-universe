## Modela Sê Navendan

**Human-Centered Universe (HCU)** gerdûnek vegotî ya vekirî, zindî û bê sînor e. Ew ji girêkên çîrokan, hilbijartinên Observer û têkiliyên sedî bi sê navendan pêk tê.

- **HUMAN CENTER** — mana mirovî, rûmet, irade, têkilî û berpirsiyarî
- **LIGHT CENTER** — zanîn, rêk, ravekirin, ewlehî û piştrastkirin
- **DARK CENTER** — ihtimal, azadî, nediyarî, afirandin û veguherîn

```text
HUMAN + LIGHT + DARK = 100
```

Her çîrok dikare fikrek serbixwe be; lê têkiliyên di navbera çîrokan de hişmendiyek mezintir diafirînin.

> **Her çîrok fikrek cuda ye. Têkilî hişmendiyek mezintir diafirînin.**
