# İnsan Merkezli Evren

**Human-Centered Universe (HCU)** üç çekirdek etrafında sürekli genişleyen açık bir anlatı evrenidir:

- **Light Center / Aydınlık Merkez**
- **Dark Center / Karanlık Merkez**
- **Common Center / Ortak Merkez**

## Dil politikası

**Canonical kaynak dil İngilizcedir.**

İngilizce, canon metnin ve ortak üretimin referans dilidir. Diğer diller aynı hikâyenin çeviri katmanlarıdır.

```text
BRG-0001
├── content/en.md   # canonical
├── content/tr.md   # kontrol edilmiş çeviri
└── meta.json
```

Çeviri durumları: `canonical`, `reviewed`, `community`, `machine_draft`.
