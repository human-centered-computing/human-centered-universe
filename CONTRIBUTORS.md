## How contributors are added

A contributor may be added to this file after an accepted contribution or after taking a continuing project role.

Contribution records should, where possible, include:

- contributor name,
- GitHub username or another stable public identifier,
- contribution role,
- relevant story / asset / component identifiers,
- pull request or commit history,
- applicable license.

Minor contributions do not need to be manually summarized here if they are already preserved accurately in Git history, but meaningful creative or continuing contributions should be made visible.

## Credit is not hierarchy

Credit reflects **what a person contributed**, not organizational status.

Being an organization member, maintainer, or Core Team member does not create authorship by itself.

Likewise, a contributor does not need to be a GitHub organization member to receive full attribution.

## Licensing of contributions

The default contribution license follows the artifact:

- **software/source code → AGPL-3.0**
- **book/story/translation/art/audio/video/creative content → CC BY-SA 4.0**

Contributors retain copyright in their original contributions unless a separate written agreement explicitly says otherwise.

By submitting material for inclusion, contributors confirm that they have the rights necessary to license it under the applicable project license.

## Attribution for adaptations

For CC BY-SA 4.0 creative material, a practical attribution record should identify:

- the original work or story,
- the original author(s),
- the source,
- the CC BY-SA 4.0 license,
- whether modifications were made.

For example:

```text
Based on "Story Title" by Author Name,
Human-Centered Universe,
licensed under CC BY-SA 4.0.
Modified by Contributor Name.
```

## Automated and AI-assisted work

AI systems and automation may assist with translation, analysis, coding, narration generation, formatting, or other workflows.

They are treated as **tools**, not automatically as human authors or copyright holders.

Human contributors remain responsible for reviewing submitted material, confirming rights, and identifying the human contribution and applicable license.

## Source of truth

For detailed provenance, consult:

1. story or asset metadata,
2. Git commit history,
3. pull requests and reviews,
4. this `CONTRIBUTORS.md` file,
5. `AUTHORS.md` for principal creative authorship.
