# Das Formular

Das Formular umfasste nur eine Seite.

Es wurde nach meinem Namen, Datum, Grund, Genehmigung und Unterschrift gefragt.

Ich fragte, warum dieselben Informationen, die bereits an anderer Stelle gespeichert waren, erneut geschrieben werden mussten.

„Weil das die Form ist“, sagten sie.

Das Merkwürdige war, dass niemand glaubte, dass die Form nützlich sei. Sie haben es abgeschlossen, weil alle anderen es abgeschlossen haben.

Eines Tages stoppte eine fehlende Unterschrift einen gesamten Prozess. Die Arbeit war beendet. Das Ergebnis war fertig. Lediglich die Unterschrift fehlte.

Die Leute warteten.

Ich habe gesehen, wie eine fertige Sache unvollendet wurde, weil eine Zeile auf einer Seite leer war.

An diesem Abend fragte ich einen älteren Arbeiter, ob ihm die Form wichtig sei.

Er sagte: „Es ist wichtig, weil es wichtig ist.“

Ich habe diesen Satz aufgeschrieben.

Jahre später wurde mir klar, dass dies die kürzeste Definition von institutioneller Zirkularität war, die ich je gehört hatte.
