## ERFAHRUNGSSCHWELLE ◇ — REALITÄTSBRÜCKE

Wählen Sie eine Idee, die Sie in der realen Welt umsetzen möchten.

Ein Bildungsmodell.

Ein KI-System.

Eine öffentliche Dienstleistung.

Eine Gesundheitsanwendung.

Ein Rechtsmodell.

Eine Arbeitsmethode.

Eine städtische Lösung.

Eine Technologie.

Beantworten Sie zuerst diese Frage:

**Welches reale Problem versuche ich zu lösen?**

Statt Ihre Idee sofort zu skalieren, führen Sie sie durch acht Tore:

**1. Was ist hier anders?**

Warum könnte eine anderswo funktionierende Lösung in diesem Kontext andere Ergebnisse liefern?

**2. Was wissen wir nicht?**

Welche Daten fehlen dem Modell?

**3. Wer entscheidet?**

Empfiehlt die KI nur, oder ersetzt sie die Entscheidung?

**4. Wessen Erfolg ist der Erfolg?**

Erzeugt die Verbesserung einer Kennzahl für einen anderen Menschen einen Verlust?

**5. Wie begegnen sich lokales Wissen und Modellwissen?**

Bleibt Erfahrung unsichtbar?

**6. Wer trägt bei einem Fehler Verantwortung?**

Verschwindet Verantwortung hinter der Maschine?

**7. Wer leistet Wiedergutmachung, wenn Schaden entsteht?**

Wird nur das System korrigiert, oder werden auch die Folgen für den Menschen bearbeitet?

**8. Wo steht der betroffene Mensch in der Entscheidung?**

Ist er nur eine Datenquelle?

Oder Subjekt der Entscheidung?

Wenn Sie diese Fragen durchlaufen haben, gehen Sie nicht direkt in eine großflächige Umsetzung.

Wenn möglich:

- richten Sie einen begrenzten Pilot ein,
- legen Sie eine klare Laufzeit fest,
- lassen Sie einen Weg zurück offen,
- ermöglichen Sie unabhängige Prüfung,
- messen Sie die Auswirkungen auf Menschen,
- schaffen Sie einen Einspruchskanal,
- verbergen Sie Scheitern nicht,
- leisten Sie Wiedergutmachung,
- veröffentlichen Sie das Ergebnis transparent.

Fragen Sie sich anschließend:

**„Wächst dieses System, weil es erfolgreich ist, oder weil tatsächlich belegt wurde, dass es für Menschen besser ist?“**

Denn Human-Centered Universe gibt uns keine fertigen Systeme.

**Es gibt uns Fragen, mit denen wir Systeme prüfen können, bevor sie größer werden als die Menschen.**
