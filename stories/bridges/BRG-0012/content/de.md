## ERFAHRUNGSSCHWELLE ⟁ — SUCHE NACH EINEM NEUEN SYSTEM

Denken Sie an ein System in der realen Welt, das Sie verändern möchten:

ein Bildungssystem,

ein Rechtssystem,

eine Institution,

eine Stadt,

eine künstliche Intelligenz,

ein Gesundheitssystem,

eine Arbeitsordnung,

ein Familienmodell,

eine Regierungsform.

Produzieren Sie nicht sofort eine Lösung.

Stellen Sie zuerst die Fragen der drei Zentren.

### HUMAN

**Was bedeutet dieses System für den Menschen?**

Wer gewinnt Macht?

Wer verliert Macht?

Bleibt der Mensch Subjekt?

### LIGHT

**Wie wird das System verstanden, verifiziert und sicher gehalten?**

Welche Belege sind nötig?

Wie wird ein Fehler erkannt?

Wer muss Rechenschaft ablegen?

### DARK

**Was könnte sonst noch möglich sein?**

Ist die heutige Regel wirklich notwendig?

Kann ein anderes Modell ausprobiert werden?

Verhindern wir das Neue, bevor es überhaupt entstehen kann?

Erzeugen Sie dann statt einer einzigen Lösung einen **Geschichtenknoten**.

Zeigen Sie die Welt, in der das System funktioniert.

Zeigen Sie, wo es erfolgreich ist.

Zeigen Sie, wo es dem Menschen schadet.

Lassen Sie eine Gegengeschichte widersprechen.

Und fragen Sie sich:

**„WELCHE FOLGE DIESES SYSTEMS MÜSSEN WIR HIER ERLEBEN, BEVOR WIR ES IN DER REALEN WELT BAUEN?“**

Denn das Ziel des Human-Centered Universe ist nicht, die Zukunft vorherzusagen.

**Es soll einen gemeinsamen Raum schaffen, um darüber nachzudenken, welche Zukünfte wir nicht bauen wollen und welche Möglichkeiten wir gemeinsam prüfen sollten, bevor wir die Zukunft bauen.**
