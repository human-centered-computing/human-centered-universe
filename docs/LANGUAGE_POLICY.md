# Language Policy

English (`en`) is the canonical repository language of Human-Centered Universe.

## Idea language and story language

Authoring distinguishes two concepts:

- **Idea language**: the language in which the contributor expresses the initial idea.
- **Story language**: the language in which the literary story should be generated and experienced.

They may be different.

For example:

```text
Idea language: tr
Story language: de
```

The AI understands the Turkish idea and writes the literary story in German.

## Canonical English layer

Every story node must contain:

```text
content/en.md
```

If the selected story language is not English, the same node also contains:

```text
content/<story-language>.md
```

The English file must be a faithful canonical version of the same story, not a different narrative.

## Translation status

Supported repository statuses are:

```text
canonical
reviewed
community
machine_draft
```

The English canonical layer uses:

```json
{"status":"canonical"}
```

A non-English version generated by AI uses:

```json
{"status":"machine_draft"}
```

After human review it may be promoted to:

```json
{"status":"reviewed"}
```

Translations always retain the same story ID.

## Reader fallback

The authoring interface may support more languages than the reader UI localization files.

If story content is unavailable in the selected reader language, English is the fallback.

## Cultural adaptation

A cultural adaptation that materially changes the story is not treated as a translation. It becomes a new story node with its own ID and explicit relationship to the original node.
