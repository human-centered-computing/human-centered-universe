# Full Book Canon Migration — v0.2

## Source reviewed

The migration was prepared from the current **V0.10 — Human-Centered Transformation Architect** manuscript before the story files were generated.

## Canon updates applied

### Character and role continuity
- Main character: **Maran**
- Children: **Rodi** and **Murat**
- Maran came to Europe for a PhD in **Human-Centered Artificial Intelligence**
- Current professional role: **Human-Centered Transformation Architect**

### Third core terminology
The official third core is now **Common Center / Ortak Merkez**.

Legacy manuscript occurrences of “Human Center / İnsan Merkezi” were normalized where they referred to the official third core.

### Stone Network
The Stone Network is modeled as its own live story node:

`BRG-0001 — The Stone Network`

It sits between **The Seven Witnesses of the Dream** and **Shahmaran's Silence** in the canonical reading path.

The mystery is topological:
- rooms / intersections = nodes
- passages = links
- bottlenecks = gates
- seven excavation zones = subnetworks
- missing center = unresolved node

No ancient electronic computer is asserted. The resemblance to distributed or quantum structures is treated as narrative analogy unless independently supported.

### Culture and belief
The migration preserves the rule:

> See the similarity without erasing the difference. Explore the connection without inventing a single origin.

Names, myths and belief traditions are not used to infer a person's religion or to collapse distinct traditions into one doctrine.

### Open-universe production
The Open Architects chapter now explicitly connects the fictional architecture with the repository model:
- commit history = visible contribution history
- branch = possibility
- fork = alternative universe
- pull request = proposed connection
- merge = temporarily stabilized shared reality

A fork is not failure.

### Interactive reading
Experience Thresholds now have structured metadata.

The GitHub Pages reader stores responses in browser-local storage as a **World Seed**. This version records the seed without pretending that all later visual or narrative branches are already implemented.

### Languages
Every migrated story contains:
- canonical English
- reviewed Turkish

## Migration result

The first book now consists of **21 live canon nodes**, including the already published `BRG-0002 — First Vibration`.
