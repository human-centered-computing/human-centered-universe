# Local Human Names Migration — v0.4

The narrative no longer uses numbered character-like labels such as `M1`, `X1`, `A1`, and `K1`.

## Canonical names

- `M1` → **Maran**
- `X1` → **Luka**
- `A1` → **Ayo**
- `K1` → **Rojin**

The names are locally used human names from different cultural contexts. Their narrative functions do **not** imply that any culture, nationality, religion, or ethnic group is inherently analytical, emotional, mnemonic, or otherwise defined by a trait.

The Four Names chapter states this explicitly.

## Record X

`Record X / Kayıt X` remains an archival file title because `X` is a technical record label, not a person's name.

The human figure inside that archive is now referred to as **Nadir**. The story keeps uncertainty about whether Nadir is the figure's legal or historical identity.

## Technical IDs

GitHub story IDs such as `COM-0002`, `BRG-0012`, and `LGT-0001` remain unchanged. They are repository identifiers, not character names.

## Unchanged system names

Names such as **Alpha One** and **Center-Zero** remain because they designate networks/processes rather than human characters.
