# Upload Instructions

This ZIP is a **repository-root update package** for:

`human-centered-computing/human-centered-universe`

It contains the files that must be added or replaced for the current HUMAN / LIGHT / DARK architecture.

## Upload from your computer

1. Extract the ZIP.
2. Open the repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload the extracted folders/files while preserving their paths.
5. Commit the upload to `main` (or upload to a branch and merge after review).
6. Open **Actions** and confirm that validation and GitHub Pages deployment succeed.

## Existing media

Large unchanged image/audio assets already in the repository are intentionally not duplicated in this update package. Uploading this package over the repository leaves those files untouched.
